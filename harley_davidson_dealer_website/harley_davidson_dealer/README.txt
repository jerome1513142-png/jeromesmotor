IRON & ROAD — Harley-Davidson Dealer Website
=============================================

Isi folder:
- index.html  : Struktur website
- style.css   : Styling, layout responsif, dan animasi
- script.js   : Menu mobile, filter motor, favorit, dialog detail, dan validasi formulir

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html di browser modern.
3. Untuk pengalaman terbaik, gunakan koneksi internet karena font dan foto demo memakai URL eksternal.

Catatan:
- "IRON & ROAD" adalah nama konsep dealer fiktif untuk demo, bukan situs resmi Harley-Davidson.
- Foto diambil melalui URL Unsplash Source-style image URLs; tampilan foto memerlukan internet.
- Formulir masih demo front-end dan belum mengirim data ke server.
- Nama model pada kartu merupakan contoh tampilan. Konfirmasi model, spesifikasi, harga, dan ketersediaan melalui dealer resmi.
